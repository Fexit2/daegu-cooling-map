# 밤낮쉼표 — 대구 폭염·열대야 그늘 쉼터 지도 (시연 웹)

2026 대구광역시 기후·환경·탄소중립 공공데이터 AI 활용대회(부문 1) 제안서용 **동작하는 모바일 앱형 시연 웹**입니다.
빌드 도구·서버·프레임워크 없이 정적 파일만으로 돌아가고, `deploy/` 폴더를 그대로 올리면 배포됩니다.

---

## 1. 실행

```bash
cd deploy/daegu-cooling-map
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000  (모바일 390×844 기준)
```

- `index.html`을 `file://`로 직접 열어도 동작합니다(데이터를 `data/bundle.js`로 넣었기 때문).
- 지도 타일은 OpenStreetMap을 실시간으로 받습니다. **네트워크가 없으면** 타일만 빠지고 데이터 레이어(그늘 밀도·마커·야간 공백)는 그대로 그려지며, 화면 상단에 `오프라인 — 배경지도 없이 데이터만 표시 중` 배지가 뜹니다.
- 외부 CDN을 쓰지 않습니다. Leaflet은 `vendor/leaflet`에, 폰트는 기기 기본 서체(애플 SD 고딕 네오 / 맑은 고딕 / Noto Sans)를 씁니다.

## 2. 화면 구성 (4탭 · 하단 탭바)

| 탭 | 내용 |
| --- | --- |
| **지금** | 폭염/열대야 히어로(SVG·모션) + 시연 위치 3곳(범어동·동성로·성서) + "지금 걸어갈 만한 그늘"(주간: 그늘 점수순) / "밤 23시에 문 열어둔 곳"(야간: 실제 운영시간 기준) + 핵심 지표 4개 |
| **지도** | Leaflet 실제 지도. 주간 = **그늘 띠**(가로수 107,144그루 래스터) + 무더위쉼터 핀(100m 내 가로수 0그루는 주황 경고) + 그늘막 파라솔 뱃지 + **최단길 vs 그늘길 두 경로와 하단 비교 카드**(탭으로 강조 전환). 야간 = 23시 개방 6곳·22시 마감 4곳 핀과 800m 점선 원 + **야간 사각지대 존** + AI 개방 후보. 마커 클릭 → 바텀시트 상세 |
| **사각지대** | 실측 인사이트 3종 — ① 100m 내 가로수 0그루 쉼터 154곳(구별 막대) ② 22시 이후 11곳(0.9%)·23시 6곳, 시간대별 운영 곡선 ③ 시 본청 135곳 vs 수성구 자체 대장 224곳 대조 + 우선 개방 후보 5곳 |
| **안내** | 네이티브 앱 전환 로드맵 3단계, 앱에서 달라지는 것 4가지, 쓴 공공데이터 출처(URL·기준일), 데이터 한계 고지 |

상단 `[낮 14시] [밤 23시]` 칩이 **시연 상태 전환**입니다. 누르면 히어로·지도 레이어·목록·지표·테마가 한 번에 바뀝니다(라이트 모드 기본, 야간은 열대야 모드).

## 3. 데이터 파이프라인

원천: `documents/대구-탄소중립-공공데이터-AI-대회/data/`
산출: `data/bundle.js` (`window.__BAMNAT__`, 약 640KB)

| 산출물 | 원천 | 처리 |
| --- | --- | --- |
| `cells` 3,329개 | 가로수 정제본 107,144행 | 위경도 0.0018°(≈200m) 격자 집계. 셀마다 그루 수 + 그늘 기여도(수령·흉고직경 가중) |
| `shelters` 1,199개 | 무더위쉼터 목록(xlsx) | 운영시간 파싱(시작·종료·연장), 냉방기·수용인원·좌표. 쉼터별 100m 내 가로수 그루 수(공간 버킷) |
| `canopies` 128개 | 수성구 그늘막 CSV | 주소 → OSM Nominatim 지오코딩(1,128건 요청, 1.15초 간격). **건물·시설 정밀 27 / 도로 중심선 근사 53 / 미매칭 48** |
| `gapcells` 766개 | 쉼터 좌표 | 800m(도보 약 10분) 안에 22시 이후 운영 쉼터가 없는 500m 셀 |
| `cands` 60개 | 쉼터 1,063곳 | 개방 후보 점수 = 유형(공공 38·특정계층 20) + 냉방기 + 수용인원 + 공백 거리 + 주변 쉼터 밀도 |
| `segments` 292개 | 달서·달성 가로수길 | 구간 시작·끝 좌표(개별 나무 데이터가 없는 구의 그늘 근거) |
| `routes` 3개 | OSRM 보행 네트워크 + 가로수·그늘막 좌표 | 시연 위치 3곳 → 가장 가까운 쉼터. 최단길(가장 짧은 보행 경로) / 그늘길(그늘 자원 경유). 거리·그늘 비율은 8~10m 샘플링 추정치 |
| `data/shade_raster.png` · `night_gap.png` | 가로수 좌표 · 쉼터 좌표 | 8m/px 반투명 래스터. 그늘 띠(가로수 밀도) / 야간 사각지대(쉼터 밀집 × 800m 밖) |

재현: `documents/대구-탄소중립-공공데이터-AI-대회/build_web_data.py` (지오코딩 캐시 `data/shade_geocode_cache.json` 포함). 실행하면 `deploy/daegu-cooling-map/data/bundle.json`이 다시 생성되고, `bundle.js`는 그 JSON을 `window.__BAMNAT__ =`로 감싸 저장합니다.
경로·래스터는 별도 1회 스크립트로 만듭니다(둘 다 네트워크 필요).

```bash
python3 tools/build_routes.py    # routes 3개 → data/bundle.json·bundle.js
python3 tools/build_rasters.py   # data/shade_raster.png · night_gap.png · raster.js
```

## 4. 원본에서 확인한 수치 (화면에 쓴 값)

- 무더위쉼터 **1,199곳** — 22시 이후 운영 **11곳**(좌표 보유 10곳, 1곳은 원본 좌표 없음), 23시 기준 실제 개방 **6곳 / 7곳**.
- 시간대별 문 열린 쉼터: 14시 1,199 → 18시 235 → 20시 12 → 22시 7 → 23시 6.
- 100m 내 가로수 0그루 쉼터 **154곳**(가로수 6개 구 582곳의 26.5%) — 서구 39.8%(35/88), 남구 36.0%, 수성구 28.9%.
- 야간 개방 시설까지 800m 밖 쉼터 **1,063곳(88.7%)**.
- 수성구: 시 목록 135곳 vs 구 대장 224곳 / 냉방 보유 시 135·구 134 / 야간 운영 시 4곳·구 0곳.

## 5. 검증 (2026-11-17, Chromium 390×844 DPR2)

- 콘솔 에러 **0**, 페이지 예외 **0**, 가로 넘침 **0** — `tools/verify.py`(로컬 HTTP + Chromium 390×844 DPR2)
- 지도: 그늘 띠 래스터(3381×3200) 로드, 핀 33개, 경로 2개(캔버스 렌더러), 비교 카드 렌더
- 경로 카드 탭 → 강조 전환, 칩 토글, 쉼터 핀 → 바텀시트, `사각지대 보기` → 탭 이동 동작
- 낮↔밤 전환·위치 3곳(범어동·동성로·성서) 전환 시 카드 수치 갱신
- 실패 요청 0 — 확대·이동 중 Leaflet이 스스로 취소한 타일 요청(`ERR_ABORTED`)은 오류 집계에서 제외

- 스크린샷: `downloads/daegu_bamnat_v2_map_day.png` · `daegu_bamnat_v2_map_night.png` (지도),
  `downloads/daegu_bamnat_1_now_day.png` ~ `daegu_bamnat_7_info.png` (나머지 탭)

## 6. 하다 만 것 / 일부러 뺀 것

- 24시간 편의점·지하철역 좌표 데이터는 이번에 확보하지 못해 **개방 후보에서 제외**했습니다. 후보는 공공시설·특정계층이용시설만 대상입니다.
- 서구·동구 그늘막은 data.go.kr OpenAPI(키 발급 필요)라서 넣지 못했습니다. 지도에는 **수성구 128곳 중 지오코딩 성공 80곳**만 표시합니다.
- 군위군은 가로수 데이터가 없어 그늘 띠가 비어 있습니다(안내 탭에 고지).
- **그늘 비율은 추정치**입니다. 가로수 좌표에서 8~10m 간격으로 샘플링해 "그늘로 볼 수 있는 구간"의 비율로 계산했고, 나무 수관 폭·시간대·건물 그림자는 반영하지 않았습니다. 카드 하단에 그렇게 적었습니다.
- 경로는 OSM 보행 네트워크 기준이며, 실제 보행로 사정(공사·계단·횡단보도 대기)은 반영되지 않습니다.
- 달서구·달성군은 개별 가로수 좌표가 없어 가로수길 구간 자료로만 그늘을 계산합니다(성서 시연 경로의 그늘 비율이 낮게 나오는 이유).
- 실시간 기상(기온·특보)은 연결하지 않았습니다. 히어로의 36.2°C·28.4°C는 **시연 시나리오 값**이고 화면에 "실시간 기상 아님"을 적었습니다.
